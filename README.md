# MoneyPass

정부지원금·환급 정보와 브라우저 기반 금융 계산기. API 키·회원가입·서버 애플리케이션 없이 실행하는 정적 사이트입니다. 계산값과 검색 조건은 저장하거나 서버로 전송하지 않습니다. 광고 활성화 시 외부 광고 요청은 발생합니다.

## 실행

배포용 HTML과 CSS/JS가 저장소에 포함되어 있습니다. 실행·업로드에 Node/Python 빌드는 필수가 아닙니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

`http://127.0.0.1:4173`을 엽니다. 파일 직접 열기도 지원하지만 클립보드는 localhost/HTTPS를 권장합니다.

## 수정할 원본

- `tools/build.py`: 페이지·정책·가이드. `tools/ui_copy.py`에서 공통 화면 문구를 관리합니다. 수정 후 `python tools/build.py` 실행.
- `assets/js/finance.js`: DOM과 분리한 계산 산식.
- `assets/js/calculators.js`: 계산기 입력·결과·탭 UI.
- `assets/js/diagnostic.js`: 관련 제도 필터.
- `assets/css/style.css`: 외부 CDN·폰트 의존 없는 반응형 스타일.
- `site.config.json`: 도메인·운영 이메일·광고 설정.

생성된 HTML·`assets/js/data.js`·`assets/js/config.js`를 직접 수정하면 재빌드 시 덮어씁니다. 확인일은 공식 출처를 실제 검토했을 때만 변경합니다.

## 나중에 설정하기

`site.config.json`을 수정한 뒤 `python tools/build.py`를 실행합니다.

| 설정 | 의미 |
|---|---|
| `siteUrl` | 업로드할 HTTPS 디렉터리 주소. 하위 경로도 가능. 설정 후 canonical·OG URL·XML 사이트맵과 robots의 Sitemap 항목 생성 |
| `contactEmail` | 운영 문의 이메일. 이용자 메일 앱에서 초안 열기 제공 |
| `adsense.client` | 실제 게시자 ID |
| `adsense.autoAds` | 자동광고 사용 여부. 개별 슬롯·광고 단위는 만들지 않음 |
| `adsense.loadScript` | 독립 페이지에서 스크립트를 로드하려면 true. 외부 환경에서 이미 제공하면 false |

설정 파일은 공개됩니다. SMTP 비밀번호·API 키 등 비밀정보를 넣지 마세요. 문의는 사이트 서버에 접수하지 않으며 이용자의 메일 앱에서 발송을 완료해야 합니다. 도메인이 비어 있으면 임의 canonical·XML 사이트맵을 만들지 않습니다.

사용자가 제공한 게시자 ID와 문의 이메일을 반영했습니다. 자동광고 로더는 배포된 최상위 웹페이지에서만 삽입하며 localhost·파일 미리보기·iframe에서는 광고를 요청하지 않습니다. 실제 광고 게재·위치는 AdSense의 해당 사이트 자동광고 설정에 따릅니다.

`calc.ssoxxl.com` 계산왕으로 홈·메뉴·관련 계산기 링크를 제공합니다. 링크는 새 탭에서 열리고 입력값은 URL 등에 전달하지 않습니다. 연결 대상 사이트 코드는 이 저장소에서 수정하지 않습니다.

| 청년도약계좌 | 2025년 이후 소득구간별·납입액별 기여금 | 신규 가입 종료. 동일 납입·고정금리 시나리오. 기여금 은행이자·과거 계좌 이력 제외 |
| 병원비 | 공단 인정 대상액·개인별 상한액·기지급액 | 상한액 직접 확인 후 입력. 지원금 중복 등 심사 조정 제외 |
| 퇴직금·세금 | 실제 날짜·3개월 일수·365일 산식·통상임금 비교·공제·누진세 | 주 15시간 이상 단일 근속. 중간정산·제외기간·비과세·IRP 이연 제외 |
| 국민연금 | 공단 정상 월액 기준 월 0.5% 조기감액/0.6% 연기가산·동일 종료 연령 | 원래 연금액 임의 추정 없음. 추가가입·물가·세금·현재가치 제외 |
| 연말정산 | 일반 카드 사용분·25% 문턱·기본 한도·연금저축 600만/IRP 등 합산 900만 | 자녀 등 추가 한도·특별사용분·세율구간 이동·다른 공제 제외. 실제 환급액 아님 |

각 화면에 출처·확인일·계산 가정을 제공합니다. 검색은 관련 제도를 좁히는 기능이며 전체 자격을 심사하지 않습니다. 금액을 합산하지 않고 종료된 모집은 기본 검색에서 제외합니다.

## 검증

Node 22 이상과 Python 3.10 이상 권장. 브라우저 테스트는 설치된 Google Chrome을 사용합니다.

```powershell
npm ci --cache .npm-cache
npm test
npm run test:browser
python tools/check_site.py
```

산식 경계값·0원·빈값·음수·윤년·추천 회귀를 검증합니다. 브라우저 테스트는 자체 localhost 서버를 열어 320·360·768·1440px에서 모든 페이지·계산기·검색·입력 오류·기존 URL을 확인합니다. 홈·계산기에는 axe 접근성 검사도 수행합니다. 외부 요청은 차단해서 실제 광고 노출을 발생시키지 않습니다. 캡처는 `artifacts/`에 저장합니다.

## 배포 ZIP

```powershell
python tools/package.py
```

`dist/moneypass-site.zip`에는 HTML·assets·guides·robots 및 설정된 사이트맵만 포함됩니다. 같은 디렉터리 구조로 업로드하세요. `.git`·개발 의존성·테스트는 포함하지 않습니다. 워드프레스 연동은 작업 범위에 포함하지 않습니다.

Cloudflare Pages Git 연동 시 프로덕션 브랜치 `main`, 빌드 명령 `python tools/package.py`, 출력 디렉터리 `dist/site`로 설정할 수 있습니다. 배포 대상 파일만 이 폴더에 복사됩니다. `ads.txt`와 AdSense 계정 확인용 메타태그도 생성합니다. 하위 디렉터리에 올릴 경우 도메인 루트의 `ads.txt`는 별도로 반영해야 합니다.
